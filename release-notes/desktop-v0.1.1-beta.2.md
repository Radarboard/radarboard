# Radarboard Desktop desktop-v0.1.1-beta.2

Second public desktop beta for validating the refreshed Radarboard macOS app package.

## Highlights

- Refreshes the Radarboard desktop, macOS, favicon, PWA, iOS, and Android icon assets so the shipped app no longer uses the old icon set.
- Includes the latest desktop release automation updates, including improved macOS release handling and updater metadata preparation.
- Carries the dependency refresh and generated asset updates that landed after `desktop-v0.1.1-beta.1`.

## Install notes

- Download the `Radarboard-0.1.1-beta.2-macos-aarch64.dmg` asset from this GitHub prerelease.
- This beta is built for Apple Silicon Macs.
- Existing beta users can replace the previous Radarboard app in `/Applications` with this build.
