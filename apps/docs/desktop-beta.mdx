# Desktop Beta

Radarboard desktop beta releases are published from the canonical GitHub repository:

<Card title="Radarboard Releases" icon="download" href="https://github.com/Radarboard/radarboard/releases">
  Download the latest macOS beta DMG and read release notes.
</Card>

## Current beta channel

- Public release repo: [`Radarboard/radarboard`](https://github.com/Radarboard/radarboard)
- Beta tag format: `desktop-vX.Y.Z-beta.N`
- First beta tag: `desktop-v0.1.1-beta.1`
- Homebrew tap repo: [`Radarboard/homebrew-radarboard`](https://github.com/Radarboard/homebrew-radarboard)

## Direct download

Open [GitHub Releases](https://github.com/Radarboard/radarboard/releases), choose the latest `desktop-v*-beta.*` prerelease, and download the macOS DMG asset.

## Internal dev QA before beta

Maintainers should test an installed local dev app before publishing another desktop beta. Use the repository desktop workflow to build and launch `Radarboard Dev.app`, which keeps manual QA separate from the public beta install and regular local Radarboard data.

<Note>
Use the local dev app for launch, tray menu, helper process, firewall prompt, onboarding, settings, integrations, notifications, logs, restart, and release-like install checks before tagging a public beta.
</Note>

## Homebrew beta

After the beta cask sync PR is merged in the tap repository, install the beta with:

```bash
brew tap Radarboard/radarboard https://github.com/Radarboard/homebrew-radarboard
brew install --cask radarboard-beta
```

The beta cask downloads mirrored artifacts from `Radarboard/homebrew-radarboard` so Homebrew installs do not depend on private release infrastructure.

## Updates

Radarboard desktop uses Tauri updater metadata attached to GitHub desktop releases. Beta testers should stay on the beta channel until a stable desktop release is published.
