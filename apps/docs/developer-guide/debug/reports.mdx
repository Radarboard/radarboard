## Purpose

Use Reports to inspect generated artifacts from assistant workflows, including analysis outputs and exports.

## When to use it

- A report is missing or stale.
- You need to confirm when a report was generated.
- An exported analysis does not match the conversation that produced it.

## What to inspect

- Report title.
- Generated timestamp.
- Age.
- Available actions.

## Common troubleshooting flow

1. Find the report by title or generated time.
2. Compare it with the source conversation.
3. Open [Conversations](/developer-guide/debug/conversations) for thread context.
4. Open [LLM Traces](/developer-guide/debug/llm-traces) if the generated content looks wrong.
