# SEO Performance Widget

The SEO Performance widget shows search analytics from Google Search Console through the shared widget runtime.

## What it displays

### Compact view
- Top search queries table with: query, clicks, impressions, CTR, average position

### Expanded view
- Summary KPIs (total clicks, total impressions, average CTR, average position)
- Clicks and impressions trend charts over time
- Full query table with sorting

## Shared system

SEO Performance uses:

- `kpi-row`
- inline `list`
- expanded shared table patterns
