# Analytics Widget

The Analytics widget provides web analytics from OpenPanel through shared headline, KPI, and inline-list primitives.

## What it displays

### Compact view
- **Live visitor count** (real-time)
- Key metrics: visitors, sessions, page views, bounce rate
- Shared inline top-pages list

### Expanded view
- Referrer breakdown
- Visitor trend sparkline
- Platform breakdown
- Full top pages table with page views and unique visitors

## Shared system

Analytics uses:

- `headline-stat`
- `kpi-row`
- inline `list`
