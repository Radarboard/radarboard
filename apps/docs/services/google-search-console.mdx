# Google Search Console

Google Search Console provides search analytics data: top queries with clicks, impressions, CTR, and average position, plus date-based trend data.

## What it powers

- **SEO Performance widget** -- Top queries table with all metrics
- **SEO expanded view** -- Click/impression trend charts and summary KPIs

## OAuth setup

Google Search Console uses Radarboard's hosted OAuth broker. Users connect their own Google account, and the hosted Radarboard app stores the Google refresh token. Local or desktop clients store only an opaque broker token and request short-lived access tokens when they fetch Search Console data.

<Steps>
  <Step title="Create a Google Cloud project">
    Go to [console.cloud.google.com](https://console.cloud.google.com/). Create a new project (or use an existing one).
  </Step>
  <Step title="Enable the Search Console API">
    In the API Library, search for **Google Search Console API** and enable it.
  </Step>
  <Step title="Create OAuth2 credentials">
    Go to **APIs & Services** > **Credentials** > **Create Credentials** > **OAuth 2.0 Client ID**.
    
    Select **Web application** as the application type. Add this Authorized redirect URI:

    ```text
    https://app.radarboard.app/api/auth/google/callback
    ```
    
    Note the **Client ID** and **Client Secret** for the hosted Radarboard deployment.
  </Step>
  <Step title="Configure the broker">
    Set the OAuth client values on the hosted Radarboard app. Local and desktop clients can use the default broker URL.
  </Step>
</Steps>

## Environment variables

```bash .env.local
OAUTH_GOOGLE_CLIENT_ID=xxxxxxxxxxxx.apps.googleusercontent.com
OAUTH_GOOGLE_CLIENT_SECRET=GOCSPX-xxxxxxxxxxxx
RADARBOARD_OAUTH_BROKER_URL=https://app.radarboard.app
```

## API details

| Property | Value |
|----------|-------|
| API base URL | `https://searchconsole.googleapis.com/webmasters/v3` |
| Rate limit | Standard Google API quotas |
| Cache TTL | 5 minutes |
| Authentication | OAuth2 through hosted broker |
